# 개발 검증 기록

환경: Linux, Python 3.12.14, NumPy 2.3.5. 웹캠과 DISPLAY 없음.
PyPI 메타데이터에서 MediaPipe 1.1.1 확인. 패키지 설치는 files.pythonhosted.org 네트워크 정책으로 차단됨.
따라서 실추론/카메라/GUI 실행을 검증 완료라고 표시하지 않음.
GitHub 비공개 저장소 생성 완료. 연결 API가 새 저장소에 404를 반환하여 브라우저 UI로 소스를 단계별 업로드함.

1. 프로젝트 구조·설정 검증: `python -m unittest tests.test_config -v`.

2. Tasks 어댑터·좌표계·영상 시간 테스트 3개 통과. 실제 MediaPipe 추론은 의존성 다운로드 제한으로 미검증.

3. OEF 합성 테스트 4개 통과: 정지 노이즈 감소, beta 증가 시 상대 지연 감소, 실제 dt, 잘못된 시간/관절별 freeze.

4. 이상값·선택 보정 테스트 4개 통과. 빠른 손/손가락 합성 움직임 보존, 국소 점프, 전체 이동의 불확실성, 예측 만료 확인. 임계값은 합성 테스트 출발값이며 실측 최적값이 아님.

5. 상태·복구 테스트 8개 통과. EMA on/off 경로의 OEF 내부 배열 동일성, 정상 복귀, 타임아웃 전환, 긴 상실 후 숨김/재동기화, 불규칙 시간, 빠른 움직임 보존 확인.

6. 동일 관측 재생·JSONL/CSV 기록·분석 테스트 4개 통과. 참값 없는 세션에서는 RMSE=null. GUI와 실제 카메라는 미검증.

7. GUI/CLI, 시나리오 기록, 전체 28개 합성·단위 테스트 통과. Tk 화면·실카메라·MediaPipe 모델 추론은 이 환경의 카메라/화면/패키지 다운로드 차단으로 미실행. 종료 시 GUI는 worker 파일 flush를 기다리도록 수정.

8. 합성 시나리오 180프레임×7종, 30fps, seed=7로 파라미터 조정. 초기 `min_cutoff=1.5, beta=0.4`는 빠른 손목 움직임에 원본 대비 지연 약 66.7ms(2프레임), 참좌표 RMSE 0.0299(영상 가로 단위)로 과도했음. `min_cutoff=2.5, beta=5.0`으로 변경하면 원본 대비 지연 약 33.3ms(1프레임), RMSE 0.0153. 그러나 이는 원본의 합성 진실 RMSE 0.00149보다 높아, 지연/안정성을 위해 정확도를 희생할 수 있다는 한계가 드러남. 정지 좌표의 좌표축별 표준편차 평균은 원본 0.001488 → 전체 보정 0.000682 (약 54% 감소). 단일 관절 점프 시 기록된 큰 점프 2 → 0; 전체 동시 점프도 2 → 0. 오클루전 후 복귀 시간 약 0.567초, 전체 출력 가용률 97.2% (원본 93.3%). 이 값은 **생성 데이터를 이 머신에서 평가한 결과이며 일반적인 카메라 정확도나 실시간 FPS 측정값이 아님**. 빠른 손가락 및 오클루전에서는 필터 적용 참좌표 RMSE가 원본보다 커질 수 있음. 수치 측정 구간과 지표 종류는 README 참고.

9. 최종 `python -m unittest discover -s tests -v`: 테스트 30개 통과 (약 1.9초). `python -m compileall -q handlab`, `git diff --check` 통과. 단일 GUI 실행은 `DISPLAY`가 없어 실패 메시지 처리만 테스트; OpenCV와 MediaPipe 실행은 설치가 차단되어 인터페이스 구현의 실제 호환성이 미검증. GUI 렌더링 및 실제 영상 처리 성능은 사용자의 PC에서 실측할 것.

### GitHub 상태

`hwcho9876/mediapipe-hand-tracking-correction` 저장소는 GitHub UI에서 Private 표시를 확인함. 이 환경의 GitHub 연결 도구에서는 새 저장소 조회가 404이고 직접 `git push` 인증도 되지 않아, 웹 UI를 이용하여 구조·추적·OEF·이상값·복구·실험·GUI·테스트·문서를 각 단계별 **원격 커밋**으로 업로드함. 웹 업로드는 로컬 Git 커밋을 전송하는 방식이 아니므로 **원격 커밋 해시와 로컬 커밋 해시 및 계보가 서로 다름**. 로컬 작업 디렉터리의 `origin` 주소가 같은 이름을 가리켜도 이 둘을 그대로 `git push`하면 이력이 갈라져 거절될 수 있다. 협업이나 후속 개발은 원격 저장소를 새로 clone하여 진행하고, 로컬 원본 이력은 별도 소스 아카이브의 `.git`으로 보존한다. 카메라 실험 후 변경 사항은 새 clone에서 커밋한다.
